# ЕРА Вива – Система: карта

Статична страница с интерактивна карта (Mind Map) на работната система „ЕРА Вива – Система“. Показва какво работи, какво е в тест, какво е на пауза и кои идеи чакат. Има втори изглед „Седмица“ с графика по дни.

- Само HTML, CSS и чист JavaScript. Без build, без npm, без външни библиотеки.
- Публикува се през GitHub Pages. Страницата е с `noindex`, а `robots.txt` забранява индексирането.
- Съдържанието е само в `data/system-map.json`. Кодът не съдържа имена на елементи.

> Ако отвориш `index.html` направо от диска, браузърът (Chrome) не разрешава четене на JSON. Страницата ще предложи да избереш `data/system-map.json` ръчно. През GitHub Pages или локален сървър (`python3 -m http.server`) работи без това.

## Файлове

| Файл | Какво е |
|---|---|
| `index.html` | страницата |
| `assets/map.css`, `assets/map.js` | стилове и логика |
| `data/system-map.json` | единственият източник на съдържанието |
| `robots.txt` | `Disallow: /` |

`data/system-map.json` се обновява всяка седмица от насрочената задача „ЕРА – седмичен преглед на системата“. Ръчни промени по него са допустими.

## Как се добавя или променя елемент

Всеки елемент е запис в масива `nodes`. Нов елемент = нов запис, без пипане на кода.

```json
{
  "id": "skill-example",
  "branch": "content",
  "type": "skill",
  "status": "testing",
  "label": "/primer",
  "name": "Умение /primer",
  "description": "Какво прави, в 1–2 изречения.",
  "trigger": "какво го пуска",
  "result": "какво се получава",
  "schedule": "понеделник, 10:00",
  "links": ["sheet-content-plan"]
}
```

- `id` – уникален, латиница, без интервали.
- `branch` – `id` на клон от `branches`.
- `type` – `skill`, `automation`, `task`, `data`, `folder`, `channel`, `page`, `rule`, `tool`, `rubric`, `project`.
- `status` – `works`, `testing`, `paused`, `idea`.
- `label` – кратък етикет на картата (до 28 знака); `name` – пълното име за подсказката и за чата.
- `trigger`/`result` и `schedule` са по желание. `links` – `id`-та на свързани елементи; връзката важи и в двете посоки.
- Ако `links`, `branch` или `node` в `week`/`daily` сочи към несъществуващ `id`, кодът го прескача и пише предупреждение в конзолата.

**Стрелки на потока.** Масивът `flows` съдържа двойки `["откъде", "накъде"]` – посоката на действието или информацията, напр. `["sheet-content-plan", "make-buffer"]`. Двата елемента трябва да съществуват. Връзка без запис във `flows` остава ненасочена. По подразбиране стрелките се виждат само при задържане върху елемент. Превключвателят „Всички стрелки“ горе вляво на картата ги показва всички; изключен, връща изгледа по подразбиране.

Нов клон: добави `{ "id": "...", "name": "..." }` в `branches`. Нов запис в графика: добави в `week[].items` или в `daily` ред с `time`, `text` и `node`. Датата „Състояние към“ идва от `updated`.

## Линк към чата

Клик върху елемент (на телефон – втори допир) отваря нов чат в Claude проекта с попълнен, неизпратен текст. Проектът е `projectId` в JSON.

## Какво да не се добавя

Сайтът е публичен. Без ID-та от Drive, Make или Canva, телефони и лични данни.
